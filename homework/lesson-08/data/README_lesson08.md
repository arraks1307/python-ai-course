Урок 8. Новые столбцы в таблице Titanic

Источник
Учебный файл titanic.csv (одна строка — один пассажир). Работа выполнена на рабочей копии `work`, исходная таблица `df` не менялась.

Размер
Число пассажиров: 891. Исходные столбцы сохранены, добавлены три новых.

Правила новых столбцов
| Столбец | Правило | Что нельзя узнать |
| Family_size | SibSp + Parch + 1 (единица — сам пассажир) | Не показывает всю семью, друзей и причину выживания |
| Is_alone | True, если Family_size равно 1, иначе False | Не доказывает, что человек ехал один |
| Age_group | «Младше18» при Age < 18, «От18» при Age >= 18, иначе «Неизвестный» | Не даёт точного возраста внутри группы |

Неизвестный возраст
У 177 пассажиров возраст неизвестен. Мы не заменяли его нулём или средним: в Age остались пропуски, а в Age_group у этих строк подпись «Неизвестный».
