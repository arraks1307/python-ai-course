# Результат урока 10

## Источник и выборка
Исходный файл titanic.csv: 891 пассажир, 342 выжили, у 177 пассажиров возраст неизвестен. Для H3 выбраны 216 пассажиров первого класса.

## Мой вопрос
Как различается доля выживших по портам посадки внутри первого класса (признак Embarked_for_analysis)?

## Результаты с n и долями
- Порт C (Шербур): n = 85, выжили 59, доля 69,4%.
- Порт S (Саутгемптон): n = 127, выжили 74, доля 58,3%.
- Порты Q (n = 2) и «Неизвестно» (n = 2) слишком малы для сравнения.
- Для сравнения, по классам: 1 класс — 216 человек, 63,0%; 2 класс — 184, 47,3%; 3 класс — 491, 24,2%.

## Ограничения
Сводка показывает связь порта и исхода, но не причину. Не учтены пол, возраст, размер семьи. Группы Q и «Неизвестно» из двух человек нельзя сравнивать с остальными. Доли относятся только к пассажирам первого класса.
